# BD_LAB_08 — Trabajos de Base de Datos (UNSA)

Repositorio de trabajos del curso de **Base de Datos** (UNSA, Escuela de
Ingeniería de Sistemas). Contiene laboratorios y ejercicios prácticos
desarrollados a lo largo del curso.

## Proyecto final: GestProy

El **proyecto final** del curso está en la carpeta [`GestProy/`](GestProy/):
un sistema de gestión de proyectos empresariales con toda la lógica de
negocio implementada en PostgreSQL (triggers, funciones/procedimientos
PL/pgSQL y vistas), consumida por una aplicación Spring Boot sin ORM.

Ahí está toda la información relevante: código fuente, documentación
detallada, diccionario de datos y guía de puesta en marcha. Ver
[`GestProy/README.md`](GestProy/README.md) para más detalle.

El resto del repositorio corresponde a ejercicios de laboratorio previos,
sin relación directa con el proyecto final [`GestProy/`](GestProy/).
